# Decisions

Records follow Michael Nygard's architecture decision record: context, decision, and consequences. Status values are the ones used by adr-tools (`Accepted`, `Proposed`, `Rejected`, `Deprecated`, `Superseded`). Dates are ISO 8601. The next record is `ADR-019`.

| ID | Date | Status | Decider | Context | Decision | Consequences |
| --- | --- | --- | --- | --- | --- | --- |
| ADR-001 | 2026-11-07 | Accepted | David | The old dex was one row per species, with an empty `card_image`. The cards index also lists trainers and energy. | `pokedex/dex.json` holds `pokemon`, `sets`, and `cards`. A species row keeps its sprite and gains `card_image` plus `card_ids` when a card name matches. | Trainers and energy have a place to live. Existing species rows stay in `pokemon`. The file grows with each printing's price history. |
| ADR-002 | 2026-11-07 | Accepted | Build | Species rows repeat a national number for alternate forms, and many cards share a name with a shorter species. | A card id is `{set code}-{collector number}`. A species id is the dex number plus the name. A card links to the longest species name that equals the card name or begins it at a word boundary. The species `card_image` is the newest linked print by release date, then collector number. | `Mega Charizard X ex` can attach to Mega Charizard X ahead of Charizard. Two forms with the same national number stay separate rows. |
| ADR-003 | 2026-11-07 | Superseded | David | Each card page exposes a small image and a full-size `data-src`. | `card_image` stores the full-size Limitless URL. The archive does not download image files. | Superseded by ADR-013. The dex stays text. The picture is gone if that URL is removed. |
| ADR-004 | 2026-11-07 | Accepted | David | The requested source was `https://limitlesstcg.com/cards`, the international index. | Crawl international sets only. If an international card page lists a Japanese print, store that print as a reference. Do not crawl `/cards/jp`. | Japanese-only cards are absent. A JP row in `prints` is not a full card record. |
| ADR-005 | 2026-11-07 | Accepted | David | Card pages show a TCGplayer price and a Cardmarket price. History is loaded from `GET /api/cards/{cardId}/prices`. | USD is the TCGplayer price and EUR is the Cardmarket price. Integer API values are cents and are stored as currency units. Each history point is a UTC date and a price. The numeric `cardId` comes from the card page. | A card with no listing has null prices and an empty history. History cannot be fetched until that numeric id is known. |
| ADR-006 | 2026-11-07 | Accepted | David | Saved history needs a cost forecast in `pokedex/dex.json`, using scikit-learn. | Fit `sklearn.linear_model.LinearRegression` separately for USD and EUR. X is days since the first point. The forecast date is 30 days after the last point. Fewer than two points leaves that currency null. A negative forecast is stored as 0. The record stores sample count, slope per day, intercept, r², last price, predicted date, and predicted price. | The forecast is a straight line through daily prices. A falling series can land on 0. |
| ADR-007 | 2026-11-07 | Accepted | David | A new entry should refit forecasts, because the site's history may have changed. Refitting every card after each of ~20,700 saves is too slow, and rewriting `dex.json` that often is too heavy. | Saving a card fits that card from the history just stored. `add_card` and `add_entry` then refit every card and write `dex.json`. The bulk scraper writes `pokedex/sets/{code}.json` after each card, rewrites `dex.json` at the end of each set, and refits every card when the run finishes. | One manual entry refreshes every stored forecast. A long scrape still stores a fresh forecast on each new card. Stopping mid-set leaves that set's cards in `pokedex/sets/`. |
| ADR-008 | 2026-11-07 | Accepted | Build | A full pass takes hours and has to survive a restart. | Skip a card when `history_ok` is true and `scraped_at` is less than 7 days old, unless the run passes `--refresh`. | `python main.py cards` continues an interrupted download. Pass `--refresh` to pull newer prices before the 7 days are up. |
| ADR-009 | 2026-11-07 | Accepted | Build | The archive is a personal download from a small public site. | Send one request at a time, wait 0.3 seconds between starts, and retry 429 and 5xx responses. The User-Agent string says the client is a personal, rate-limited archive. `--delay` changes the wait. | A pass of about 20,700 cards takes hours. Raising `--delay` slows the run further. |
| ADR-010 | 2026-11-07 | Accepted | Build | The set grid has links and images. Card text, rarity, and the numeric price id are on the card page. | Read the set index from `/cards`. For each set, read `?display=list&show=all&unique=prints&sort=set`, then open each card page, then call the price API. If the card page has no current price, keep the price from the list. | Two requests per card after the set list. List prices cover gaps on the card page. |
| ADR-011 | 2026-11-07 | Accepted | David | The first scraper mixed fetching, parsing, and saving in one function. | Split the work into `scraper/http_client.py`, `parse.py`, `predict.py`, `store.py`, and `pokedex.py`. Paths and the 30-day horizon live in `constants.py`. `main.py` is the command line. | Parsing, forecasts, and the JSON file can change on their own. `requirements.txt` lists `requests`, `beautifulsoup4`, `scikit-learn`, and `numpy`. |
| ADR-012 | 2026-11-07 | Accepted | Build | On Windows, replacing `pokedex/dex.json` raises `PermissionError` when the file is open. | Write JSON to a `.tmp` file and replace the destination. On `PermissionError`, retry, then write the bytes into the existing file. | An editor can have `dex.json` open and the save can still land. A crash during the write can leave a `.tmp` file beside it. |
| ADR-013 | 2026-11-07 | Accepted | David | The TCGplayer price guide is a current market price for each printing and grade, and it disagrees with Limitless on the USD price and the picture. Rewriting `dex.json` for every grade would be the slow part. | `pokedex/tcgplayer.sqlite` stores each set, product, and daily market price, low price, and sales. `pokedex/dex.json` stays the file to open. On a match, TCGplayer replaces `card_image`, `prices.usd`, and the condition prices. Card text, the EUR series, and older USD points stay. `card_image` is `https://tcgplayer-cdn.tcgplayer.com/product/{id}_in_1000x1000.jpg`. The previous picture URL is kept as `limitless_image`. This supersedes ADR-003. | SQLite holds the daily rows. The JSON file gains a card when the price guide lists a product the dex did not have. The picture is gone if the CDN URL is removed. |
| ADR-014 | 2026-11-07 | Accepted | David | The singles table has a printing dropdown and a condition dropdown. The condition text sometimes repeats the printing. The guide is today's market price, not a history. The headline price has to be one number so the existing USD forecast still runs. | Store Near Mint, Lightly Played, Moderately Played, Heavily Played, and Damaged, plus any other grade the guide returns, under `prices.conditions` and again per printing under `prices.printings`. The headline USD price is Near Mint for Normal when that printing exists, otherwise Near Mint for Holofoil, Reverse Holofoil, then any other printing. That price is written onto the USD history for the scrape date and the line is refit. A condition forecast is stored once that grade has two daily points. A set saved in the last 7 days is skipped unless the run passes `--refresh`. | The first pass refits USD from the history already saved plus today's Near Mint price. EUR is left as it was. A grade seen on only one day has prices and no forecast. |
| ADR-015 | 2026-11-07 | Superseded by ADR-016 | David | The archive has a rarity and a market price for each condition. David wants a free pack-opening site in the spirit of a card collector, with no accounts yet and no payments. | `web/` is Rolldex. `python main.py play` builds `web/data/catalog.json` from SQLite when it is missing and serves the site on localhost. A roll picks a rarity tier, then a card in that tier, then a condition. Damaged drops the shown tier by two and Heavily Played drops it by one. The price is that condition's market price. The collection stays in the browser. Trading is only a placeholder. The page states it is not affiliated with Nintendo, The Pokémon Company, Creatures, or TCGplayer. | Clearing the browser clears the collection. `python main.py catalog` rebuilds the pool after a price download. Card pictures load from the TCGplayer CDN. |
| ADR-016 | 2026-11-07 | Accepted | David | The static Rolldex page is hard to grow, and the layout reads like a generated template. David wants the site in Next.js, named PokeRNG, with a sidebar that can shrink, a Profile screen, and icons. | `web/` is a Next.js App Router app. The catalog stays a static file at `web/public/data/catalog.json` and the browser fetches it. `python main.py play` runs `next dev` on port 8765. The pack odds, condition prices, and rarity drop from ADR-015 stay. A saved `rolldex-v1` collection is copied into `pokerng-v1` once. Pictures stay as plain image tags pointed at the TCGplayer CDN. | Node is required to run the site. The 27k-card file is not part of the server render. Clearing the browser still clears the collection. |
| ADR-017 | 2026-11-07 | Accepted | David | The first Next.js layout used hand-written CSS, and a theme script set `data-theme` before hydration, so React reported a mismatch. David wants the interface on daisyUI. | `web/` uses Tailwind CSS 4 and daisyUI 5. The sidebar is a daisyUI drawer that stays on screen from the `lg` breakpoint and shrinks to icons. Cards use daisyUI hover-3d. `<html>` sets `suppressHydrationWarning` because the theme script still writes `data-theme` from `pokerng-theme` before paint. | The page follows daisyUI light and dark themes. One primary button is the pack action. The theme no longer throws a hydration error. |
| ADR-018 | 2026-11-07 | Accepted | David | The daisyUI page still read as generated: the default face, mixed gaps, a gradient on every card, and a different colour on every pack. | Text is Public Sans only. Radii are 4px on controls, 8px on cards, and a pill on badges. Component depth is 0, so nothing casts a shadow. Spacing stays on 4, 8, 16, 24, 32, 48. Pack bands are one neutral bar. Card scans stay the only pictures. | A new screen has to reuse those tokens. The primary button stays the only accent. |
